# Schemas and invariants

Executable MongoDB schemas: `apps/api/src/models.ts` and `apps/api/src/journey/models.ts`. Runtime request schemas: `packages/core/src/contracts.ts`, `packages/core/src/journey.ts` and `packages/connectors/src/settings.ts`. Generated JSON Schema: REQUEST_SCHEMAS.json.

IDs are UUID strings except explicit public/provider keys. Dates are UTC BSON dates; amount fields are integer strings. Tenant-owned records have immutable `tenantId`, strict schemas and timestamps. All unique business keys include tenant except globally unique public/session keys and provider events tied to an owning connection. Collection names for the newer models use Mongoose pluralization; the model names below are the stable code references.

Sensitive raw content remains encrypted at rest in the application for contacts, secrets, webhook payloads, command inputs, account mail and call text. Names, operator notes and audit IDs are not all field-encrypted: encrypted database volumes, private access and restricted backups remain infrastructure requirements.

Schema changes require an explicit migration/rollback plan before production data exists. `connectDatabase` creates declared indexes; it does not automatically drop obsolete indexes. Do not use destructive `syncIndexes()` against production without reviewing differences. Current money and idempotency records are deliberately durable; privacy erasure pseudonymizes rather than deletes the financial chain.
